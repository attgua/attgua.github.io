Thesis

During my master's thesis, I collaborated with the GECO project for the ERC, focusing on Natural Language Understanding. Specifically, I developed a conversational agent aimed at aiding geneticists in the selection, filtering, and retrieval of pertinent data through natural language interactions.

  • Title: Exploring natural language understanding for developing a conversational agent to support data science tasks on genomic data (2020 - 2021)
  • Goal: developed an NLU conversational agent to assist geneticists in querying databases and executing statistical data analysis workflows.
  • Architecture & Stack: built with Rasa Open Source and custom TensorFlow Transformers; dialogue logic and custom actions in Python with SQLite backend integration.
  • Outcome: evaluated the Transformer-based NLU model against a traditional finite-state automata baseline, proving superior scalability, context flexibility, and accuracy.
